# 示例文章：使用相对路径引用图片

这篇文章演示如何在文章中使用相对路径引用图片。

## 为什么使用相对路径？

使用相对路径有以下优势：

1. ✅ **图片和内容在同一目录** - 便于管理和维护
2. ✅ **重命名目录时不会破坏引用** - 相对路径自动适配
3. ✅ **Astro 自动优化** - 图片会自动转换为 WebP 等格式
4. ✅ **便于整体迁移** - 移动文章目录时图片一起移动

## 目录结构

```
example-post-with-images/
├── index.md       # 当前文件
├── cover.png      # 封面图片（示例）
└── images/        # 内容图片目录
    ├── screenshot1.png
    └── screenshot2.png
```

## 引用方式

### 封面图片

在 frontmatter 中使用相对路径：

```yaml
---
coverImage: "./cover.png"
---
```

### 内容图片

在 Markdown 中使用相对路径：

```markdown
![封面图片](./cover.png)

![截图 1](./images/screenshot1.png)

![截图 2](./images/screenshot2.png)
```

### 代码示例

```markdown
# 我的文章

![文章封面](./cover.png)

## 开始

这里是文章开头。

![第一个示例图](./images/screenshot1.png)

## 继续

这里更多内容。

![第二个示例图](./images/screenshot2.png)
```

## 注意事项

1. **路径必须以 `./` 开头** - 表示当前目录
2. **图片必须在同一文章目录下** - 不能引用其他文章的图片
3. **支持子目录** - 可以在文章目录下创建 `images/` 等子目录
4. **与绝对路径共存** - 可以继续使用 `/imgs/` 等绝对路径引用公共图片

## 与绝对路径的对比

### 相对路径

```markdown
![图片](./cover.png)
```

- ✅ 便于管理
- ✅ 便于迁移
- ✅ 与文章绑定

### 绝对路径

```markdown
![图片](/imgs/blog-cover-1.jpg)
```

- ✅ 可以在多篇文章间共享
- ✅ 简单直接
- ❌ 不便于整体迁移

## 总结

相对路径引用是文章组织的最佳实践，特别是对于图片较多的文章。建议：

- **新文章**：优先使用相对路径
- **旧文章**：可以继续使用绝对路径，两者都支持
- **公共图片**：使用绝对路径放在 `/imgs/` 等公共目录
